# 190 mm 黑框尺寸校正与机器人 X 轴分格

## 黑框与螺母尺寸

`config/vision/nut_detector.yaml` 中 `frame_size_mm: 190.0` 表示黑框外边界的实际边长，
两个方向均为 190 mm。这个尺寸在 ROI 内缩、腐蚀之前使用，不能改成内缩后区域的边长。

检测器要求黑框具有四个按边界顺序排列的凸四边形角点。对同一个黑色边框的内外轮廓，
优先选择通过几何检查的外轮廓。保留透视下的梯形角点，不使用图像最小外接矩形替代。

角点建立到 190×190 mm 平面的单应性变换；所有接受的螺母外轮廓通过同一变换得到毫米轮廓。
尺寸描述量为 `size_mm = sqrt(4 * area_mm2 / pi)`，即外轮廓面积对应的等效圆直径。
它用于比较大小，不是螺纹规格或六角对边尺寸，中心孔不从外轮廓面积中扣除。

ROS 适配器用有效 `CameraInfo` 的 K/D 对角点和轮廓点去畸变，再计算单应性。
图像检测本身仍在原图进行；像素中心、像素半径和深度采样坐标不被毫米尺寸替换。
无内参的离线输入按无畸变针孔图像处理。

完整任务顺序模块和预抓 `/nut_detections/large` 均按 `size_mm` 选择目标。
顺序模块必须接收与像素观测一一对应的有效毫米尺寸；尺寸缺失时不会退回像素排序。
大、中、小仍是本轮剩余物体的相对尺寸排序，任务阶段只由显式事件推进。

Hough 候选没有测得的外轮廓，即使开启兼容开关也只记录诊断，不参与毫米尺寸分类。
原有像素面积、半径阈值仍负责排除噪声和粘连候选；改变分辨率或极端视角后仍需验证这些阈值。
此模型近似螺母外轮廓与黑框共面，物体厚度、边界拟合误差仍会影响实际毫米精度。

## 靠近黑框边线的螺母

搜索区域改为黑框实际内边界围成的纸面区域。优先从未闭运算的黑色掩膜查找包围纸面的
孔轮廓，用凸包消除螺母连接造成的局部内凹，拟合四条直边并求交点。反光边框使用局部阈值
补充；局部阈值形成多重环时取最内层的框尺寸孔轮廓，避免把边框自身当作纸面。

`frame_inner_scale` 默认改为 `1.0`，不再进行原来的 94% 内缩和 9×9 腐蚀。
只用 3×3 腐蚀去掉孔轮廓携带的一像素级黑边。内边界用于搜索，外边界仍用于 190 mm 尺寸标定。
调试图以细黄色线显示检测到的内边界，离线结果增加 `frame_inner_contour`；`roi_mask.png`
显示实际可搜索区域。

靠内边界四像素范围保留原始灰度，避免高斯模糊把间隔 1～2 像素的螺母和黑线混合。
删除固定的三像素轮廓距离、以及“中心距离必须大于像素半径加三”的额外排除条件。
改为检查真实轮廓及其开闭运算前的连通区域是否被搜索边界截断；被截断的候选记录为
`contour_clipped_by_frame`，不会把压线物体的残片当作一颗更小的螺母。

短时缓存同时保存外边界和内边界，不缓存螺母。当前图像与缓存均不能提供完整搜索区域时，
`frame_found=false`，不能将“没有有效搜索区域”解释为“黑框内没有螺母”。
该处理仍要求图像中能分辨螺母与黑线的间隔；真实压线、遮挡或低分辨率下完全粘连的图像
不能保证恢复完整外轮廓。

## 蓝框与格子

蓝色候选必须为近似凸四边形，轮廓与最小外接矩形的面积比不低于
`min_basket_rectangularity: 0.75`，且轮廓与凸包的面积比不低于 0.90。
圆形、L 形及不满足矩形约束的较大蓝色物体不作为置物框。

`slot_axis: robot_x` 是当前支持的分格方式。先将四角通过深度和采集时刻 TF 转换为
`base_link` 坐标，然后在 `[xmin, xmax]` 范围沿 X 等分为三段。三格中心 X 为：

```text
xmin + (xmax - xmin) * 1/6
xmin + (xmax - xmin) * 3/6
xmin + (xmax - xmin) * 5/6
```

每个 X 位置与蓝框 XY 多边形求交，取该截面的 Y 中点，保证中心位于框内。
编号固定沿机器人 +X 增长：slot_1 的 X 最小，slot_3 的 X 最大。
格子中心处的深度用于放置 Z，避免把蓝框边缘高度当作格子底面高度。
这是针对机器人 XY 平面上置物框的几何三等分，并未检测真实隔板。

缺少任一角点/中心的有效深度，或无法转换到 `base_link` 时，不发布有效三格结果。
单张二维离线图没有机器人轴信息，因此只框出蓝色四边形，不再绘制旧的图像长轴格子估计。
在线调试图在定位成功后绘制三个中心及 `(+base X)` 编号。

## 输出与验证

- `/nut_detections/status` 的螺母记录增加 `size_mm`，原有位置和任务话题保持兼容。
- 离线 `result.json` 使用 schema 2，包含 `size_mm` 和尺寸描述量名称；
  `slot_estimates_px` 为空，原因是 `requires_depth_and_robot_frame`。
- `planar_geometry_test` 验证近远尺寸反转、同物体不同位置的尺寸一致性、190 mm 标尺和 X 轴分格。
- `nut_detector_core_test` 用透视合成图验证完整轮廓检测与尺寸校正，并检查蓝色圆形/L 形干扰物。
- `nut_border_test` 覆盖不同黑框像素大小、线宽、六角朝向、四边和四角的近边目标，检查中心和
  毫米尺寸，并验证旋转黑框、压线拒绝及内外边界缓存。
- `nut_sequence_test` 验证像素大小与毫米大小相反时按毫米排序，并拒绝缺失/无效尺寸。
- ROS `slot_observation_test` 使用合成 RGB-D 图和静态 TF，验证预抓与顺序分类一致、
  相机旋转后的机器人 X 轴分格，以及缺失 TF 时没有伪装成机器人坐标的结果。
