# 数据备份说明

## 需要备份什么

| 内容 | 位置 |
| --- | --- |
| SDK 源码 | `/home/simon/lbot_ws/src` |
| 驱动配置 | `src/lbot_driver/config/lbot_config.yaml` |
| launch 文件 | `src/*/launch/*.launch.py` |
| 模型资源 | `开发资源/assets` |
| 相机标定 | `开发资源/calibration` |
| 工具坐标系 | 从控制平台或 ROS2 服务记录 |
| 比赛代码 | 队伍自己的代码目录 |

## 一键打包

```bash
cd /home/simon
tar --exclude='lbot_ws/build' --exclude='lbot_ws/install' --exclude='lbot_ws/log' \
  -czf lbot_ws_backup_$(date +%Y%m%d_%H%M%S).tar.gz lbot_ws
```

## 单独备份配置

```bash
mkdir -p /home/simon/lbot_ws/开发资源/config_backup
cp /home/simon/lbot_ws/src/lbot_driver/config/lbot_config.yaml \
  /home/simon/lbot_ws/开发资源/config_backup/lbot_config_$(date +%Y%m%d_%H%M%S).yaml
```

## 工具坐标系记录表

| 时间 | 机械臂 | 名称 | x | y | z | roll | pitch | yaw |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
|  | left/right |  |  |  |  |  |  |  |

查询当前工具坐标系：

```bash
ros2 service call /robot1/left_arm/get_current_tool_frame lbot_arm_interfaces/srv/GetCurrentFrame "{}"
```

## 什么时候备份

- 比赛前备份一次。
- 改完 IP、launch、工具坐标系后备份。
- 标定相机后备份。
- 程序跑通关键流程后备份。
- 设备故障后保存日志。
