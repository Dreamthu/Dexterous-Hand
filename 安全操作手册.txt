# 安全操作手册

## 最重要的几条

- 运动前确认工作区没有人。
- 运动前确认急停按钮随手能按到。
- 新程序第一次运行必须低速、小幅度。
- 机械臂使能后，不要拆装夹具、相机、线缆。
- 发现抖动、异响、碰撞趋势，立即急停。

## 开机前

| 检查项 | 要求 |
| --- | --- |
| 机械臂底座 | 固定牢靠 |
| 灵巧手 | 安装牢靠 |
| 线缆 | 不会被机械臂扫到或拉扯 |
| 工作区 | 无人员、无障碍物 |
| 网络 | 电脑和机器人在同一网段 |

## 运动前

1. 打开 Web 控制平台或启动 ROS2 驱动。
2. 确认当前关节状态正常。
3. 确认目标点不会撞桌面、机器人本体、相机或夹具。
4. 先用小速度运行。
5. 一人操作，一人看急停最好。

## ROS2 急停

左臂急停：

```bash
ros2 service call /robot1/left_arm/set_emergency_stop lbot_arm_interfaces/srv/SetEmergency "{emergency: true}"
```

左臂恢复：

```bash
ros2 service call /robot1/left_arm/set_emergency_stop lbot_arm_interfaces/srv/SetEmergency "{emergency: false}"
```

右臂把 `left_arm` 换成 `right_arm`。

## 使能和掉使能

使能：

```bash
ros2 service call /robot1/left_arm/set_enable lbot_arm_interfaces/srv/SetEnable "{enable: true}"
```

掉使能：

```bash
ros2 service call /robot1/left_arm/set_enable lbot_arm_interfaces/srv/SetEnable "{enable: false}"
```

## 标零要谨慎

`set_zero` 会把当前位置当成新的零点。除非明确知道当前姿态就是零位，否则不要随便调用。

## 灵巧手安全

- 第一次动作给小速度、小力矩。
- 手指夹住东西后，不要继续加大闭合值。
- 没有触觉传感器时，程序不知道自己夹得多紧。
