# 机器人基础参数

## 设备组成

本次资料按“双臂 + 双 O6 灵巧手”整理。模型资源中的整机名称为：

```text
lkls73_i1_o6_bimanual
```

模型包含：

| 部件 | 数量 |
| --- | --- |
| 躯干底座 | 1 |
| 7 轴机械臂 | 2 |
| LinkerHand O6 灵巧手 | 2 |

## 机械臂参数

| 项目 | 参数 |
| --- | --- |
| 自由度 | 单臂 7 自由度 |
| 左臂末端 link | `arm_left_L8_Link` |
| 右臂末端 link | `arm_right_R8_Link` |
| 控制器默认 IP | `192.168.10.21` |
| Web 控制平台 | `http://192.168.10.21:8000` |
| 固件升级页面 | `http://192.168.10.21:5000` |
| ROS2 默认命名空间 | `/robot1` |
| 状态发布频率 | 约 50 Hz |

## O6 灵巧手参数

| 项目 | 参数 |
| --- | --- |
| 型号 | LinkerHand O6 |
| 主动关节 | 6 |
| mimic/被动关节 | 5 |
| 单手总关节 | 11 |
| ROS2 控制数据 | `UInt8MultiArray` |
| 控制值范围 | 0~255 |

## 单位提醒

| 数据 | 单位 |
| --- | --- |
| 关节角 | rad |
| 末端位置 | m |
| 欧拉角 | rad |
| 灵巧手位置/速度/力矩 | 0~255 |

角度换算：

```text
rad = degree * pi / 180
degree = rad * 180 / pi
```
